دليل طالب الحاسبات

افهم جهازك واختار مواصفاته حسب استخدامك

دليل مبسّط يشرح وظيفة كل قطعة، والفرق بين اللابتوب والكمبيوتر المكتبي، وأهم البرامج والمواصفات التي تحتاجها للدراسة.

اعرف مكوّنات الجهاز شوف البرامج والمواصفات
اعرف القطع الأساسية

كل قطعة: فائدتها وأنواعها

01

المعالج CPU

ينفّذ أوامر البرامج ويؤثر في سرعة الجهاز.

أنواعه: Intel Core أو Core Ultra، وAMD Ryzen. توجد فئات موفرة للطاقة وأخرى أقوى للأعمال الثقيلة.

للدراسة: Core 5 أو Ryzen 5 حديث يكفي غالبًا
02

الذاكرة RAM

مساحة عمل مؤقتة للبرامج المفتوحة؛ زيادتها تساعد على تعدد المهام.

أنواعها: DDR4 أو DDR5. في اللابتوب تكون غالبًا SO-DIMM أو ملحومة، وفي المكتبي DIMM ويمكن ترقيتها عادةً.

16GB مناسبة، و32GB للمونتاج والمشاريع الثقيلة
03

كرت الشاشة GPU

يعالج الصور والفيديو والرسوم ثلاثية الأبعاد.

أنواعه: مدمج داخل المعالج للدراسة والبرمجة، أو منفصل مثل NVIDIA GeForce وAMD Radeon للألعاب والتصميم والمونتاج.

لا تحتاج كرتًا منفصلًا إلا إذا كانت برامجك تستفيد منه
04

التخزين SSD

يحفظ النظام والبرامج والملفات، ويؤثر في سرعة فتحها.

أنواعه: NVMe M.2 الأسرع والأكثر شيوعًا، وSATA SSD الأقدم. القرص HDD أبطأ ويصلح للأرشفة أكثر من تشغيل البرامج.

ابدأ بـ512GB SSD، واختر 1TB للمشاريع والملفات الكبيرة
05

الشاشة

مساحة عملك اليومية؛ الدقة والألوان والسطوع تفرق في الراحة والتصميم.

أنواع شائعة: IPS لألوان وزوايا مشاهدة جيدة، وOLED لتباين أعلى. دقة Full HD مناسبة، والتصميم يستفيد من ألوان دقيقة.

اختر 14 أو 15.6 بوصة حسب سهولة الحمل وراحة العمل
06

التبريد

يطرد الحرارة ويحافظ على سرعة الجهاز واستقراره.

أنواعه: مراوح ومشتتات حرارية في اللابتوب والمكتبي، وقد يستخدم المكتبي تبريدًا مائيًا للمعالجات القوية.

التبريد الجيد مهم عند تشغيل برامج ثقيلة لفترات طويلة
07

البطارية ومزوّد الطاقة

البطارية تشغّل اللابتوب دون توصيله بالكهرباء.

في اللابتوب: بطارية داخلية وشاحن خارجي. في الكمبيوتر المكتبي: مزوّد طاقة PSU يحوّل الكهرباء ويوزعها على القطع.

قدرة PSU في المكتبي تُختار حسب استهلاك المعالج وكرت الشاشة
08

اللوحة الأم Motherboard

تربط المعالج والذاكرة والتخزين وباقي أجزاء الجهاز.

في المكتبي: لوحة مستقلة بمقاسات مثل ATX وMicro-ATX. في اللابتوب: لوحة مدمجة ومخصصة للطراز.

تحدد التوافق وإمكانية الترقية
09

لوحة المفاتيح واللمس

أدوات الإدخال لكتابة الأوامر والتحكم بالمؤشر.

في اللابتوب: مدمجة مع Touchpad. في المكتبي: لوحة مفاتيح وفأرة منفصلتان يمكن تغييرهما.

اختر لوحة مريحة للاستخدام الطويل والكتابة

ميزة اللابتوب: شاشة ولوحة مفاتيح وبطارية في جهاز واحد، لكن ترقية المعالج وكرت الشاشة غالبًا غير ممكنة.

ميزة الكمبيوتر المكتبي: أسهل في الترقية والتبريد عادةً، لكنه يحتاج شاشة وملحقات ومساحة على المكتب.

قبل الاختيار: افحص إمكانية ترقية RAM وSSD؛ بعض اللابتوبات تأتي بذاكرة ملحومة لا يمكن تغييرها.

برامج ستستخدمها في الدراسة بالكلية

كل برنامج ومتطلبات تشغيله

الحد الأدنى للتشغيل الأساسي، والمواصفات المريحة للاستخدام اليومي. قد تختلف حسب إصدار البرنامج وحجم ملفاتك.

Microsoft Word

لكتابة التقارير والواجبات وتنسيق المستندات.

حد أدنى: معالج ثنائي النواة، RAM 4GB، ومساحة فارغة 4GB.

مريح: معالج Core 3 أو Ryzen 3 حديث، RAM 8GB، وSSD.

Microsoft Excel

للجداول والحسابات والمعادلات والرسوم البيانية.

حد أدنى: معالج ثنائي النواة، RAM 4GB، ومساحة فارغة 4GB.

مريح: معالج Core 5 أو Ryzen 5، RAM 8GB، وSSD؛ والملفات الكبيرة تستفيد من RAM 16GB.

Microsoft PowerPoint

لإنشاء العروض التقديمية وإضافة الصور والرسوم.

حد أدنى: معالج ثنائي النواة، RAM 4GB، ومساحة فارغة 4GB.

مريح: معالج Core 3 أو Ryzen 3 حديث، RAM 8GB، وSSD.

Visual Studio Code

محرر لكتابة وتشغيل الكود بلغات ومجالات متعددة.

حد أدنى: معالج ثنائي النواة، RAM 4GB، ومساحة فارغة 1GB.

مريح: معالج Core 5 أو Ryzen 5، RAM 8GB، وSSD؛ واختَر 16GB مع أدوات كثيرة أو مشاريع كبيرة.

Cisco Packet Tracer

لمحاكاة الشبكات والتدرب على توصيل الأجهزة وإعدادها.

حد أدنى: معالج ثنائي النواة، RAM 4GB، ومساحة فارغة 1.4GB.

مريح: معالج Core 3 أو Ryzen 3، RAM 8GB، وSSD.

Blender

للنمذجة والتحريك والتصميم ثلاثي الأبعاد.

حد أدنى: معالج رباعي النواة، RAM 8GB، وكرت شاشة بذاكرة 2GB.

مريح: معالج Core 7 أو Ryzen 7، RAM 32GB، وكرت شاشة بذاكرة 8GB أو أكثر.

AnyLogic

لبناء نماذج المحاكاة وتجربة سيناريوهات الأنظمة والعمليات.

حد أدنى: معالج رباعي النواة، RAM 8GB، ومساحة فارغة 5GB.

مريح: معالج Core 5 أو Ryzen 5، RAM 16GB، وSSD؛ والنماذج الكبيرة تستفيد من 32GB.

MySQL Workbench

لإنشاء قواعد البيانات والجداول وكتابة استعلامات SQL.

حد أدنى: معالج ثنائي النواة، RAM 4GB، ومساحة فارغة 1GB.

مريح: معالج Core 5 أو Ryzen 5، RAM 8GB، وSSD؛ وشغّل قاعدة البيانات المحلية مع 16GB عند العمل على بيانات أكبر.

Oracle VirtualBox

لتشغيل نظام تشغيل افتراضي داخل جهازك، مثل Linux للتدرب على أنظمة التشغيل والشبكات.

حد أدنى: نظام 64-bit يدعم الافتراضية، RAM 8GB، ومعالج ثنائي النواة. فعّل Intel VT-x أو AMD-V من BIOS/UEFI.

مريح: معالج Core 5 أو Ryzen 5، RAM 16GB أو أكثر، وSSD مع 60GB مساحة فارغة على الأقل للآلة الافتراضية.

المواصفات إرشادية للتشغيل المعتاد؛ البرامج الثقيلة أو الملفات الكبيرة والمحاكاة قد تحتاج ذاكرة ومعالجًا أقوى.

اختيار سريع

أهم المواصفات حسب الاستخدام

دراسة وبرمجة

Core 5 أو Ryzen 5 حديث · RAM 16GB · SSD 512GB

مناسبة لمعظم مواد الجامعة، البرمجة، قواعد البيانات وتطوير الويب.

تصميم ومونتاج

Core 7 أو Ryzen 7 · RAM 32GB · SSD 1TB

اختر كرت شاشة منفصلًا للمونتاج الثقيل أو المؤثرات أو التصميم ثلاثي الأبعاد.

استخدام يومي خفيف

معالج حديث موفر للطاقة · RAM 8GB على الأقل · SSD

للتصفح والمحاضرات وكتابة التقارير؛ 16GB أفضل إذا كنت ستستخدمه للبرمجة أيضًا.

ملحقات مفيدة حسب احتياجك

أشياء تكمل استخدام اللابتوب

ليست كلها ضرورية؛ اختار ما يحل مشكلة تواجهك فعلًا.

حقيبة مبطنة أو جراب

تحمي الجهاز من الخدوش والصدمات أثناء التنقل. اختار مقاسًا مناسبًا للابتوب ومساحة للشاحن، ولا تضع أشياء صلبة فوق الشاشة.

حامل لابتوب

يرفع الشاشة لمستوى النظر ويساعد على جلسة أريح وتهوية أفضل. مع الاستخدام الطويل، أضف لوحة مفاتيح وماوسًا خارجيين.

ماوس

يسهّل تحديد العناصر والسحب والعمل الدقيق في التصميم والجداول. مفيد أيضًا إذا كان استخدام لوحة اللمس متعبًا.

موزّع منافذ USB-C Hub

يوصل شاشة أو فلاشات أو شبكة سلكية إذا كانت منافذ الجهاز محدودة. تأكد من دعم منفذ USB-C للشاشة أو الشحن قبل اختيار الموزّع.

سماعة رأس بميكروفون

تحسّن وضوح المحاضرات والاجتماعات وتقلل الضوضاء حولك. الميكروفون مفيد للمشاركة في الدروس والمكالمات.

وحدة تخزين خارجية

تنقل المشاريع وتحفظ نسخة احتياطية من ملفاتك المهمة. احتفظ بنسخة أخرى في مكان منفصل؛ لا تجعلها النسخة الوحيدة.

لوحة مفاتيح خارجية

تساعد على الكتابة براحة عند استخدام حامل اللابتوب، وتفيد إذا كانت لوحة الجهاز صغيرة أو غير مريحة. ليست ضرورية إذا كانت لوحة اللابتوب مناسبة لك.

قاعدة تبريد

قد تساعد على تحسين تدفق الهواء عند تشغيل برامج ثقيلة لفترة طويلة أو إذا كانت فتحات التهوية أسفل الجهاز. ابدأ بتنظيف فتحات التهوية ووضع الجهاز على سطح صلب؛ القاعدة اختيارية وليست بديلًا عن الصيانة.

المواصفات المذكورة إرشادية؛ راجع متطلبات إصدار البرنامج ومشروعاتك قبل الاختيار.
